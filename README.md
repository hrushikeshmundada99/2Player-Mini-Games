# 2 Player Mini Games 🎮

A collection of 2-player arcade mini games built with Python and Pygame.

## Games Included
- 🏓 Table Tennis
- ⚽ Penalty Kicks
- 🎱 Pool Billiards
- 👋 Red Hands

## How to Run

1. Make sure Python is installed
2. Install Pygame:
pip install pygame
3. Run the game:
python main.py

## Controls

| Game | Player 1 | Player 2 / AI |
|------|----------|---------------|
| Table Tennis | W / S | ↑ / ↓ |
| Penalty Kicks | Mouse Click | A / D |
